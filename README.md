# Clube dos Calvos

Aplicativo Windows para jogar, conversar e compartilhar a tela com os amigos.

## Baixar e instalar

[**Baixar a versão mais recente**](https://github.com/lfelipeambrosio/clube-dos-calvos-downloads/releases/latest)

Abra o link, baixe o instalador `.exe` em **Assets** e execute. Se o app já estiver aberto, feche-o antes de instalar. Sua conta e suas preferências são mantidas.

## Atualizar quando quiser

A partir da versão 1.3.0, o ícone de atualização na barra superior indica quando há uma nova versão. Clique para ler as novidades e baixar quando quiser. A instalação só começa depois que você confirmar **Reiniciar e instalar**.

Você pode continuar usando o aplicativo enquanto a atualização estiver disponível. Não há download, reinício ou instalação obrigatórios.

Este repositório distribui os instaladores e o manifesto de atualizações. O código-fonte fica em um repositório privado.
